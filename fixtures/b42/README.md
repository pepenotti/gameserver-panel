# B42 fixtures

Captured on 2026-09-23 from Project Zomboid **42.20.4 (b0bbce05d5)** — the
GameServer bundled with the Steam client, run on Windows during the M1 spike.
Files are byte-exact (CRLF, no final newline) except that the admin and RCON
passwords are replaced with `<ADMIN_PASSWORD>` / `<RCON_PASSWORD>`.
Log files are the game's stdout+stderr lines without any prefix.

See `docs/verification-log.md` for what each one demonstrates.
